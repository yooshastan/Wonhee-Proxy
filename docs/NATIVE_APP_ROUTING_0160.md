# 0.16.0 Batch B — selected-app routing pilot
0.15.92 device PASS: 3 handshakes, 12 TCP flows, 4 x 2 MiB sustained downloads, 60 UDP DNS transactions, no native/reply rejects, TUN and peers closed. Keep the scoped regression launcher available in this debug build.
New launcher: Wonhee App Routing Lab. Import two IPv4 full-Internet peers (explicit /0 or both /1) and optional Home peer; user selects one authorized RFC1918 CIDR. Secure hostname bootstrap unchanged. Choose 1–32 installed launcher apps; saved local categories, individual Exit A/B/block override, category Exit A/B/block, default exit, and global TCP/UDP destination-port overrides. Private Home destinations override public exit policies; other private and special-use destinations blocked. Explicit public-traffic blocks win, then global port rule overrides individual and category exit assignments; individual then category then default. Android 29+ VPN connection-owner API; unidentified traffic dropped except fixed 1.1.1.1:53 resolver traffic with missing/system UID (global port rule or default). Shared/ambiguous visible UID refused. No broad package permission. Fixed DNS inside VPN, not DoT to resolver; Private DNS must remain OFF. DNS interception/filtering and configurable encrypted tunnel DNS deferred to C. No DPI or reliable semantic protocol identification. IPv4 TCP/UDP only, unsupported IPv6 captured and discarded. Selected apps plus the lab service UID for VPN visibility; unselected apps remain normal and ordinary lab-owned traffic is not admitted. No system-wide kill switch. Before VPN starts and after explicit Stop, normal networking resumes. In-process failure after TUN establishment holds routes and discards packets until Stop, but process death/revoke not protected.
Native uses actual allowed IPv4 routes and bounded tuple ledger, independent role/return checks; Java pins UID/role per tuple, idle expiry TCP 5 min UDP 60 sec, new TCP SYN only, no active migration, max 4096 flows. Queue congestion drops rather than reroutes. Worker owns TUN, no main-thread packet polling. Separate debug app versionCode 147; production unchanged.
