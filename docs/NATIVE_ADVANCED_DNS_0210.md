# 0.21.0 — advanced encrypted DNS preview
Baseline: 0.20.1 (917a09a35dd50eb87c29ecad8fd72d854a8e04ff), device reported 3 successful recoveries, two network migrations, 22 discarded packets, generation 4, 2522 blocked queries. Both physical migration directions observed; independent leak and retry exhaustion tests remain open.
Same debug package, versionCode 154. Default remains DoT. Select DNS protocol, provider and exit separately; DoQ supports Quad9 and AdGuard; DoH3 supports Cloudflare and Quad9 initially. Unsupported combinations rejected. Native QUIC uses pinned quic-go v0.50.0 on duplicated Java VPN-bound connected UDP descriptors, exact local port, numeric upstream, Android built-in CA roots, TLS 1.3 hostname/ALPN verification, strict DoQ framing and ID zero, HTTP/3 binary POST, no redirect, no HTTP2/plaintext/DoT fallback. No 0-RTT DNS request; one connection per QUIC transaction, bounded four workers. QUIC datagrams capped at 1252 bytes to fit IPv4 TUN MTU. Existing pre-capture endpoint bootstrap remains authenticated DoT, not selected application DNS.
Virtual TCP DNS terminates in an isolated in-memory WireGuard netstack listening only at 1.1.1.1:53, with bounded connections, DNS length framing, queue and timeouts. Only authorized captured TCP DNS reaches it. It does not open OS plaintext DNS sockets; same hosts filter, cache and encrypted upstream as UDP. UDP oversized answers return TC; TCP answers can carry up to 16384 bytes. IPv6 remains blocked. Other app-owned DNS port 53 blocked and existing optional external 853 block retained. App-owned HTTPS DNS cannot be universally identified, including HTTP/3 on UDP443. No process-death protection guarantee.
Native dependencies are resolved in a disposable build directory with existing WireGuard pin/checksums and pinned quic-go, go mod verify/checksum DB; new transitive module metadata isn't committed yet. CI adds provider matrix, bounded datagram tests and local TCP stack integration. Device tests: DoT regression, UDP and TCP resolver, DoQ Quad9/AdGuard, H3 Cloudflare/Quad9, selected DNS exit, HOSTS, no fallback on refusal, actual provider transport, cache hits, network migration while each mode is active. CI alone cannot establish these device properties.
