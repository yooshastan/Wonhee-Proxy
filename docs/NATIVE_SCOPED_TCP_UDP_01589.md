# 0.15.89 scoped TCP + UDP diagnostic

0.15.88 passed six HTTP flows on device, three peer handshakes and six protected transport sockets, one bind attempt, no protection failures. New debug increment retains those six TCP flows and adds one explicitly VPN-bound UDP socket per exit. Five example.com A queries per exit, spaced one second apart, checked by exact role, addresses, port, fixed question, DNS transaction ID, response bit, success code and nonzero answer count. No Home UDP responder assumed. No general DNS forwarding, no automatic endpoint lookup, no system DNS changes, no default route. Only app-scoped existing three /32 routes. UDP source port registered once with native TCP ports. Java and Go independently check UDP scope; response transaction correlation in Java. HTTP body samples read only with a single explicit Content-Length and no Transfer-Encoding, capped 65536 bytes; no redirects, no credentials. This is not sustained streaming or full response validation. Added redacted policy rejection categories and UDP packet counts. Existing numeric overrides remain required for hostnames. Automatic secure endpoint bootstrap and larger sustained downloads are deferred until this mixed-protocol dataplane is device verified. No production kill-switch claim.
